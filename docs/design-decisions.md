## 1. 原子话题 = 生长段，不是切分

**时间**：2026-06-19
**来源**：天干地支类比 → prompt 重构

### 旧思维

对话是一根绳子，用刀在上面找位置"切"出话题。
prompt 说"请从中提取独立的原子话题"——没有告诉 AI 在哪切、怎么切。

### 新思维

对话是一棵树。每个话题是一个**完整的生长段**——从一个想法萌发，到它自然收敛。
不是"切"出来的，是"观察"出来的。

### 天干地支五阶段

一个话题在对话中经历自然的生命阶段：

| 阶段 | 对话中的样子 | 例子 |
|------|-------------|------|
| **甲（萌发）** | 学生提到一个新概念，或问一个新问题 | "那反函数是什么？" |
| **乙（展开）** | 开始讨论，交换信息，有问有答 | "反函数就是把输入输出互换" |
| **丙（深入）** | 追问机制、因果、关联——"为什么" | "为什么单调函数一定有反函数？" |
| **丁（关联）** | 把当前概念和已有知识连起来 | "哦，那单调性和一一对应是一回事啊" |
| **戊（收敛）** | 理解达成，讨论自然结束 | "明白了" "差不多了" |

### 规则

- 一个原子话题 = 至少经历了 **甲→乙** 的完整生长段（只萌发没展开的不算）
- 两个话题的边界 = **新的甲阶段出现**（学生提出了一个与当前话题不同的新方向）
- **聊出去的内容**（侧枝）也是一次完整的生长，不要扔掉
- **回头聊**之前的话题 → 归到已有话题，不新建
- **性质转变**：如果一个段里包含了两个可独立检验的概念，检查中间是否有性质转变
  - 有转变 → 拆成两个
  - 没有转变 → 就是一个，保持完整

### 验证

用"函数"学习对话测试（14轮对话），提取到 5 个原子话题：
定义域、值域、奇偶性、单调性、反函数（聊出去的侧枝）

全部符合期望：
- ✅ 定义域和值域分开
- ✅ 奇偶性和单调性分开
- ✅ 反函数是独立话题（侧枝正确处理）
- ✅ 回头聊定义域时归并不重复
- ✅ 没有合并成单个"函数"（粒度合适）

## 2. 对话顺序 vs 知识结构 — 鱼与熊掌可以兼得

**时间**：2026-06-19
**核心洞察**：两个维度，不是一根轴。

### 错误的问题

"实时整理能看到结构，但对话顺序反映思维逻辑，怎么取舍？"

### 正确的视角

- **时间维**：对话顺序 = 思维的日记（纵向，按 timestamp 排序）
- **语义维**：知识树 = 知识的地图（横向，按 embedding 建树）

日记和地图不互斥。它们在不同维度上。

### 实现原则

- **话题提取是非破坏性的**：不改变原始对话顺序
- 所有消息都带有 `timestamp`（时间顺序）+ `nodeId`（话题归属）
- 两个维度同时存在，随时可切换：
  ```sql
  SELECT * FROM chatMessages ORDER BY timestamp  → 时间线
  SELECT * FROM chatMessages GROUP BY nodeId     → 话题分组
  ```

## 3. 实时话题分类 — 双层架构

**时间**：2026-06-19

### 为什么要实时

用户聊天时就想看到话题结构，不想等全部聊完再整理。

### 为什么不能全量跑

全量 `extractAtomicTopics` 每次 ~20 秒，太慢。

### 方案：轻量实时判断 + 定期全量整理

| | 实时判断（每轮） | 全量提取（定期） |
|---|---|---|
| **输入** | 最新一轮对话 + 已有话题标题列表 | 全部对话历史 |
| **输出** | 归属话题或新话题 | 完整的话题列表 |
| **调用方式** | DeepSeek，轻量 prompt，`reasoning_effort: "low"` | DeepSeek，完整 prompt，高耗费 |
| **耗时** | ~2-3 秒 | ~20 秒 |
| **作用** | 让 UI 实时展示话题结构 | 修正、合并、精化 |

### 执行流程

```
用户发消息 → AI 回复 → 显示消息
                          ↓（后台，不阻塞）
              轻量分类 API → 判断归属 → 更新话题结构
                ↓（积累几轮后）
              全量提取 → 合并/分裂/重命名 → 重新建树
```

### 轻量分类 prompt 要点

- 与全量版共享"生长段"思维
- 输入：用户消息 + AI 回复 + 已有话题列表 + 最近上下文
- 输出：`{ topicTitle, isNew, isSubTopic, reason }`
- 关键判断规则：
  - "为什么"、"再举个例子" → 当前话题的深入（丙），不是新话题
  - 突然提到不同概念 → 新话题的萌发（甲）
  - 回到之前聊过的话题 → 归到已有话题

## 4. 聊天 UI — 飞书式话题嵌套

**时间**：2026-06-19

### 对比旧设计

```
旧（不想要）：              新（飞书式）：
┌──────┬──────────┐       ┌──────────────────────┐
│导航路径│ 当前话题   │       │ 📌 定义域 [展开]      │
│1.函数  │ 消息...    │       │  对话...               │
│2.定义域│            │       │  📎 分母不为零 [展开] │
│← 返回  │            │       │  对话...               │
└──────┴──────────┘       │ 📌 值域 [折叠]          │
                           │ 📌 奇偶性 [折叠]        │
                           │ 📌 反函数 [折叠]        │
                           │                         │
                           │ [定义域] 输入... [发送] │
                           └──────────────────────┘
```

### 核心体验

- 所有话题在**同一个滚动流**里，不切页面
- 每个话题是一个折叠/展开的组
- 子话题嵌套在父话题内部（缩进 + 左边框）
- 输入框始终在底部，发送到"当前活跃话题"
- 点击话题标题可以切换活跃话题
- 消息的 timestamp 始终保留（线性时间不丢）

### 技术实现

- `NestedChatView` 继承自飞书式改造
- `TopicSection` 递归组件处理嵌套
- 消息按 `nodeId` 分组，按 `timestamp` 排序
- 子话题通过 `spawnedNodeId` 关联

## 5. 3D 知识树 → Tab 键临时呼出

**时间**：2026-06-19

### 为什么要改

旧设计：知识树是主界面，聊天是弹窗。
新设计：聊天是主界面，知识树是临时预览。

### 交互方式

- **Tab 按住** → 3D 树以半透明叠加层出现
- **Tab 松开** → 叠加层消失，回到聊天
- **点击节点** → 关闭叠加层，进入该话题聊天
- **底部显示提示**："松开 Tab 关闭知识树 · 点击节点进入话题聊天"

### 技术实现

- Canvas 始终保持 mounted（不销毁 Three.js 上下文）
- CSS 控制可见性：`opacity + visibility + pointer-events`
- 监听 `keydown`/`keyup` + `blur`（防止 Tab 卡住）
- 叠加层有 `backdrop-blur-sm` 半透明背景

## 6. 历史会话管理

**时间**：2026-06-19

### 痛点

每次进入应用都要重新输入主题，看不到之前的学习记录。

### 方案

- 应用首页显示"最近学习记录"列表
- 每个会话显示：📌 主题 + 最后学习时间
- 点击可**继续上次学习**（恢复话题和消息）
- 底部有"新话题"输入框

### API

- `GET /api/sessions` → 列出最近 20 个会话
- `GET /api/session?id=xxx` → 加载单个会话（含所有节点）

### Store

- `recentSessions: []` — 缓存最近会话列表
- `loadRecentSessions()` — 从 API 拉取
- `loadSession(id)` — 加载历史会话到当前状态

## 7. 整体 UI 层级

```
┌──────────────────────────────────────┐
│         第一层：首页                    │
│    TopicSelector（历史列表 + 新建）     │
├──────────────────────────────────────┤
│         第二层：聊天主界面              │
│    NestedChatView（飞书式话题聊天）     │
├──────────────────────────────────────┤
│         第三层：Tab 临时呼出            │
│    KnowledgeTree（3D 树叠加层）        │
│    ViewSelector（视角切换按钮）        │
└──────────────────────────────────────┘
```

### 导航流

```
首页 → 点"继续上次学习" → 聊天主界面
     → 输入新主题         → 聊天主界面（新会话）

聊天主界面 → Tab 按住 → 3D 树预览
           → 点击节点 → 切入该话题聊天
           → 点"返回" → 回到首页（会话列表）

3D 树预览 → 切换视角 → 树重新布局
          → 点节点 → 进入话题聊天，关闭预览
```
